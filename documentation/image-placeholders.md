# Replaceable image slots

Repeated photographs have been replaced by individual SVG placeholders. The first photograph occurrence is retained. Layout dimensions are unchanged.

To use your own photo, put it in `assets/images/` and update the matching `src` in the HTML. For dynamic product/journal slots, update the matching path in `assets/data.js`. You may replace an SVG with another SVG using the same name, or use JPG/PNG/WebP and change the path.
